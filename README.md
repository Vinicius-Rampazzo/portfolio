📋 Sobre o Projeto
Este portfólio foi desenvolvido para apresentar minha jornada como desenvolvedor full stack, destacando projetos reais, experiência profissional e certificações na área de tecnologia e segurança cibernética. O design moderno e interativo reflete minha paixão por criar experiências digitais memoráveis.
🎯 Objetivos

Showcasing Skills: Demonstrar habilidades técnicas através de projetos reais
Professional Branding: Estabelecer uma presença digital forte e profissional
User Experience: Criar uma navegação intuitiva e envolvente
Performance: Garantir carregamento rápido e otimização para SEO


✨ Principais Recursos

🚀 Como Executar
Pré-requisitos

Node.js 18+
npm ou yarn

Instalação
bash# Clone o repositório
git clone https://github.com/Vinicius-Rampazzo/portfolio.git

# Entre no diretório
cd portfolio

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run dev

# Acesse http://localhost:3000
Build para Produção
bash# Gere build otimizado
npm run build

# Execute versão de produção
npm start
